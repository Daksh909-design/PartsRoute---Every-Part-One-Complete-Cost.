# Start here

For the project, setup commands and current limits, read the [README](README.md).

- **Try it:** [sample calculator](https://daksh909-design.github.io/PartsRoute---Every-Part-One-Complete-Cost./). Prices are synthetic.
- **Run live locally:** [live setup](docs/LIVE-SETUP.md). Requires TinyFish, an AI provider, PostgreSQL and the worker.
- **Deploy independently:** [deployment](docs/DEPLOYMENT.md). Permanent hosting is not provisioned.
- **Review evidence:** [validation](docs/VALIDATION.md) and [saved observations](docs/evidence/README.md).

The repository name ends with a dot. Use its [canonical browser link](https://github.com/Daksh909-design/PartsRoute---Every-Part-One-Complete-Cost./) when sharing. The clone URL ends in `Cost..git` because one dot belongs to the repository name.
